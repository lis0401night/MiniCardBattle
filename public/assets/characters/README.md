# キャラクター画像アセット管理

本ディレクトリ（`public/assets/characters`）には、ゲーム内で使用される各キャラクターの立ち絵（通常・各スキン・敗北立ち絵・サムネイル）が格納されています。

キャラクター立ち絵の新規追加、画風リメイク、および「アイコン」「ダメージアイコン」「プレイマット」等の連動アセットの作成・トリミング仕様については、プロジェクトルートの以下の完全手順書を参照してください。

📖 **[キャラクターアセット制作・リメイクワークフロー仕様書](../../../docs/CHARACTER_ASSET_WORKFLOW.md)**

### 主なルール
- 立ち絵の規格: 800 × 1200 (アスペクト比 2:3), WebP (品質90), アルファなし
- サムネイル（`*_thumb.webp`）は `npm run build` 実行時に `scripts/generate_card_thumbnails.js` によって自動生成されます。
- アイコン・プレイマットは立ち絵からのトリミング座標をピクセル単位で正確に合わせて生成してください（位置ズレ防止）。
