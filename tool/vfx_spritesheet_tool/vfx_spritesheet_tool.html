VFX スプライトシート作成ツール

連番画像 / GIF / MP4動画 から、フレームをグリッド状に並べたスプライトシート(PNG)を作成します。すべてブラウザ内で完結し、外部送信は行いません。

入力

ここにドラッグ&ドロップ 画像を複数選択 → 連番として結合
GIFファイル1つ → 全フレームを展開
動画ファイル1つ(mp4/webm等) → 指定FPSで抽出
クリックしてファイルを選択

出力設定

スプライトシート アニメーションプレビュー

作成済みのスプライトシート画像を選択すると、列数・行数を自動推定した上でアニメーションとして再生できます(推定値は手動で調整可能です)。
